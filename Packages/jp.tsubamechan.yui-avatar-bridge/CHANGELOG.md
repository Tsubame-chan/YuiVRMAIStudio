# Changelog

## 0.2.0 (not available through the public VCC repository)

- Export a portable VRM 1 file without OS target selection or platform build modules.
- Use UniVRM/UniGLTF 0.127.2 for conversion.
- Convert mouth/blink settings, mesh customization, basic materials and spring motion.
- Process supported Modular Avatar changes on a copy through NDMF.
- Retain the legacy ZIP export API.

## 0.1.1

- Include the built-in AssetBundle module dependencies required for ZIP export.
- Check exported avatar data before creating the ZIP.
- Add installation and file transfer instructions.
- Make mobile targets optional; keep installed desktop targets selected.
