# Backend Consoleの使い方

Backendで使うAI・音声、接続先、記憶・履歴を管理する画面です。

Backendを起動し、同じPCのブラウザで `http://127.0.0.1:8000/admin/` を開きます。ポートを変更している場合はURLも合わせてください。

## 初めて使うとき

1. ホームに表示された接続先を、YuiアプリのBackend設定へ入力します。
2. 「AIと音声」で提供元・モデル・接続先を選び、保存します。PC内の音声エンジンは別途起動してください。
3. 「試す」で会話や音声生成を確認します。外部APIを使う場合は入力が提供元へ送信され、利用料金が発生することがあります。

別端末からはPCとiPhone/iPadの両方でTailscaleを導入し、同じアカウントへ接続して使えます。他の信頼できるVPNを使う場合も、アプリの接続先とBackendの待受設定を合わせます。 iPhone/iPadでは、アプリのBackend URLへPCのVPNアドレスとポートを入力します（例: `http://PCのVPNアドレス:8000`）。`127.0.0.1` は操作している端末自身を指すため、別のPCには接続できません。接続先には `/health` や `/admin/` を付けません。管理画面はBackendを起動したPCで開いてください。アプリ用APIには認証がないため、インターネットへ直接公開しないでください。

## 声を追加・調整する

「AIと音声 → 読み上げ」で「新しい声」を作り、接続先を選びます。VOICEVOX/AivisSpeechは話者・スタイル、Irodoriはモデルや声の説明などを指定します。試聴して名前を付けて保存してください。

別の音声エンジンやAPIへ接続する場合は「提供元と接続」で追加します。必要なソフトや設定手順は[音声エンジンの導入ガイド](BACKEND_TTS_GUIDE.md)にあります。

アプリのキャラクター設定で「Backendの保存した声を選ぶ」から割り当てます。別のBackendに接続した場合は、その接続先で使う声を選んでください。

「失敗時の代替音声」を設定すると、選んだ声で生成できなかった際に、その代替音声を試します。試聴では代替せず、選択した声の結果を確認できます。

## 設定とAPIキー

設定は保存後、次のリクエストから反映されます。実行中の会話やRealtimeには、開始時の設定が使われます。

APIキーは設定済みかどうかを表示し、値は再表示しません。空欄で保存しても既存キーは残ります。削除する場合は「このキーを解除」を選んでください。

設定は `backend/data/admin-settings.json`、保存した声と接続先は `backend/data/voice-library.json` に保存されます。キーを含む場合があるため、このファイルを公開・共有しないでください。既存の `.env` は保持されます。

## 記憶・履歴を管理する

「記憶」「履歴と利用状況」で、Backendの会話機能が保存した記録を管理します。対象の利用者・キャラクターと削除範囲を確認してください。下記の端末同期が保存する共有データとは別です。

日次の利用状況は目安です。料金や通信を自動で停止する機能ではありません。

## キャラクターと会話を端末間で同期する

同期に対応したアプリでは、名前・人格の指示・記憶・会話履歴を、同じBackendにつなぐ端末で共有できます。アプリに同期ボタンがない場合は、[対応版](RUNTIME_SUPPORT.md)へ更新してください。

1. このPCの「接続と設定 → 端末と同期」で登録コードを表示します。10分間・1回有効です。
2. アプリのBackend接続設定で「キャラクターと会話を同期」を開き、端末を登録します。
3. 初回は共有するキャラクターを選び、送信するデータと差分を確認します。別々に話した履歴は両方を残します。同じ記憶や人格の変更が重なった場合は、内容を比較して選びます。

次回の接続では変更がある場合に確認します。確認を取り消しても元のデータは残ります。APIキー・アバター・声の設定・音声モデルは同期しません。Secret中は同期できません。端末の時計だけで一方を最新版と判定して上書きすることもありません。

同期前の退避コピーはアプリの保存領域の`DeviceSync/Backups`に残ります。履歴や記憶を削除しても、この退避コピーは自動では消えません。現在は1回あたり最大8MiB・共有項目18,000件までで、大量の履歴を分割して同期する機能はありません。上限超過や破損時は元データを保持して停止します。

使わなくなった端末はPCの同期画面から登録解除できます。これはその端末の接続権限を解除する操作で、端末内に保存済みのデータを消す操作ではありません。

## PCでも同じキャラクターと話す

この項目とCSV集計は新しいBackendの機能です。配布済みデスクトップ版v0.2.4-beta.2に付属するBackendにはありません。該当する項目が表示されない場合は、新しいBackendが必要です。アプリを更新するだけでは、設置済みのBackendは置き換わりません。現時点では最新ソースから[Mac](MAC_PUBLIC_BETA.md#backendを使う場合) / [Windows](SETUP_GUIDE.md#backendを使う場合)の手順で準備します。既存Backendを更新・移行する前に、`.env` と `backend/data` を非公開の場所へバックアップしてください。

1. アプリからキャラクターを共有します。
2. Consoleの「接続と設定 → 端末と同期」で「端末と共有する会話・記憶」からそのキャラクターを選びます。
3. 会話を記録に残す場合は「今回の会話を保存しない」のチェックを外して送信します。既定では保存しません。外部AIを設定している場合は、その提供元への送信と料金が発生します。
4. アプリで同期すると、PCで保存した会話・記憶も受け取れます。

昔のBackendで話した内容を共有する場合は「既存のBackend記録を取り込む」で利用者・キャラクターと内容を確認します。選んだ範囲をコピーする操作で、元の記録は消えません。同じ名前だけで自動的に取り込むこともありません。

共有した記憶を2〜8件選ぶと、つながりを確認・編集して新しい記憶を保存できます。元の発言は保持します。同期するだけで出来事の順番や因果関係を自動的に事実と決める機能ではありません。[記憶の仕組み](CONVERSATION_IDENTITY.md#記憶同士のつながり)。

## CSVから集計と図を作る

Consoleの「作業」で、UTF-8のCSVファイルを選ぶか、見出しを含む本文を貼り付けます。「分類する列」と「合計する数値列」の見出しを指定して集計してください。元ファイルは変更しません。処理はこのPCで行い、外部AIへの送信・API料金はありません。

完了すると集計CSV・棒グラフ・HTMLレポートを保存できます。作業と成果物はBackendに残り、再起動後も確認できます。処理中に停止した場合は失敗として表示するため、内容を確認して再実行してください。

上限は2MiB・20,000行・100列・分類100項目です。空欄や数値でない値がある場合は、黙って除外せずエラーを表示します。現在はPCのConsoleから使う機能で、アプリのWork画面からCSVを送る操作はありません。

## うまく動かないとき

右上の「実行状況」は、応答が遅い・失敗した・想定と違う提供元が使われた時に開きます。処理ごとに、使用した提供元、待ち時間、失敗原因、次の確認先を表示します。

「原因と対処を確認」で該当処理へ移動し、「関連設定を開く」で設定を修正できます。失敗・代替・応答待ちで絞り込むこともできます。

記録は最大24時間保持され、Backendを再起動すると消えます。保持上限を超えて古い記録が省略された場合は、画面に表示します。本文・APIキー・ファイル内容は記録しません。ライブ音声の接続状態は「試す」で確認してください。
