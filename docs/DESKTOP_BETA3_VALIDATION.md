# v0.2.5-beta.3の検証範囲

> 過去の検証記録です。記載の版・成否・未確認事項は検証当時のものです。現在の[配布ファイル](DOWNLOADS.md)と[機能対応](RUNTIME_SUPPORT.md)は別途確認してください。

2026-10-11。Windowsで報告された更新問題の修正を取り込み、Macで配布版同士の更新を確認しました。

- Macの実際のBackend ZIPと配布用Pythonで更新を実行。古いパッケージ情報・不要なモジュールが消え、設定・DB・モデルは保持されました。環境切り替え後にファイル更新を意図的に失敗させ、旧環境への復元とAPIの起動を確認しました。
- 配布用PythonからIrodori V4.1を追加取得・準備し、3声すべての実WAV生成を確認。相対パスを使うportable Pythonから追加venvを作る場合の問題も修正しました。
- iOSシミュレーターで、短い取得確認画面の左右余白、Backendの3声名、モデル詳細の末尾、実ダウンロードの百分率・中止、Backendの準備中/完了通知を確認しました。Mac Playerでも共通UIと通知を確認しました。単独通知が会話タブに重ならないよう配置を修正しています。
- Sanitized sourceのUnity全EditModeは624成功・11 skipped・失敗0。その後の通知配置変更に関連する2試験も成功。Backend全体384成功・5 skipped、実際のportable環境を使う追加取得試験30件も成功。公開用のPython試験は364成功・6 skipped。配布Playerの資産監査と完成ZIPを含む配布監査も成功しました。

Windowsの新しい自動音声取得と新版PlayerはWindows実機未受入です。以前のWindows版の本人確認、共通処理の試験、Mac実機受入を区別しています。iPhoneでの今回のUI変更はシミュレーター確認であり、端末内LLM/TTSの速度・音質の実機再受入ではありません。Mac版の署名・公証は未整備です。

大容量の共通モデルは変更していないため、beta.3のManifestからSHAで固定した既存beta.2アセットを参照します。アプリとBackendはbeta.3の同じOSのZIPへ更新してください。
